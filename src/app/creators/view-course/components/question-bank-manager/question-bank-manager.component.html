Bulk import from CSV

Prepare questions in a spreadsheet and import them all at once. Download the template to see the required columns. Click Validate first to check for errors before importing.

Bulk CSV import

Supported types: MCQ and Passage (passage-based MCQ).

Required columns: type, text, chapter_id, difficulty, bloom_level.

MCQ: set options as pipe-separated (A|B|C|D) or JSON array, and correctAnswer to the correct option text.
Passage: add passage_text (the reading passage) and set question_sub_type=MCQ. Rows sharing the same passage text are automatically grouped.
